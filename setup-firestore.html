שלבי ההגדרה

1

הגדרת כללי Firestore

עבור ל-Firebase Console ועדכן את כללי Firestore:

rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { // Allow read/write access to all users (for testing) match /{document=**} { allow read, write: if request.auth != null; } } }

⚠️ זהו כלל פתוח לבדיקות בלבד. בייצור יש להגדיר כללים מחמירים יותר.

2

יצירת אוספים (Collections)

האוספים הבאים ייווצרו אוטומטית:

  • users - פרטי המשתמשים
  • tournaments - נתוני הטורנירים
  • matches - תוצאות המשחקים
